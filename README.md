# Ananya Bhattacharyya — Personal website

A responsive editorial portfolio built with plain HTML, CSS and a tiny amount of JavaScript, designed to deploy to GitHub Pages.

## Files
- `index.html` — all website text and links
- `assets/style.css` — typography, colours, layout and mobile styling
- `assets/script.js` — mobile menu and automatically updated copyright year

## Preview locally
Double-click `index.html` to open it in a browser (internet needed initially for Google Fonts). No installation or terminal needed.

## Publish
1. Create a public repository called `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html` and the entire `assets` folder to the repository **root** (not a nested folder).
3. Go to Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Visit `https://YOUR-GITHUB-USERNAME.github.io/` after deployment.

## Before making it public
- Verify your profile and research descriptions, and decide which work/employer details are appropriate to disclose.
- Add your own Medium author page, GitHub profile, and project URLs when ready.
- Replace the generic Towards Data Science homepage link with your author profile, if preferred.
- Do not put private information, internal datasets, or workplace materials in a public repository.

## Customise
- Colours are at the top of `assets/style.css` under `:root`.
- All headings, article links and descriptions are in `index.html`.
- The decorative charts are illustrative SVG/CSS graphics, not real data.
